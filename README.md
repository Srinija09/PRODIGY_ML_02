# Customer Segmentation using K-Means

## Overview
This project groups retail store customers into clusters based on purchase behavior using K-Means clustering.

## Dataset
Download dataset:
https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

Place `Mall_Customers.csv` in the project folder.

## Features Used
- Annual Income
- Spending Score

## Installation
pip install pandas matplotlib scikit-learn

## Run
python kmeans_model.py

## Output
- Cluster assignments
- Visualization of customer segments
